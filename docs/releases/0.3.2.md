# Branchman v0.3.2

## 修复

- 修复 Linux/POSIX 路径被误转成小写，导致 Git 找不到工作目录的问题；Windows 路径大小写规则保持不变。
- 修复 Actions 缺少开发依赖安装的问题，测试矩阵覆盖 Linux/Windows、Node 22/24。
- 发布前核对构建入口与提交一致，通过既有 npm OIDC 可信发布上传已测试的安装包。
- 保留 0.3.1 的独立主树布局、层级列表、折叠、筛选、祖先搜索与相机保持功能。

## 安装与验证范围

下载附件 `dsh-branchman-0.3.2.tgz` 或安装 `dsh-branchman@0.3.2`，按 [安装说明](https://github.com/mydsp/dsh-branchman/blob/main/docs/INSTALL.md) 在实际桌面 profile 登记 bundle。

114 项测试包含真实 Git、精确历史继承、文件携带、恢复日志与已构建客户端合同。此修正版的验证范围为自动测试；桌面交互证据来自 0.3.1，未声称在 0.3.2 重跑真实 Electron 验收。两小时稳定性测试按本机用户要求取消，未记为通过。

## English

Fix case-sensitive POSIX path handling and install locked build dependencies in Actions. Windows path comparison remains case-insensitive. The test matrix covers Linux/Windows and Node 22/24. Existing tree layout and outline features are retained. Publishing uses the existing npm OIDC trust and checks that built entries match committed files. Desktop interaction evidence is from 0.3.1; no new Electron acceptance or two-hour stability run is claimed for this patch.
