# Branchman v0.3.1

## 更新内容

- 独立主树分区，子树与连线按真实父子关系布局。
- 列表层级缩进、展开/收起、仓库与主树筛选。
- 搜索和分页保留祖先；默认可读缩放、选中定位、详情开关，刷新保持相机。
- 本次发行同时包含 0.3.0 的宿主与客户端接入、稳定 UUID、Git 身份保护、精确历史继承、文件携带和持久恢复日志。
- 开发依赖包含 esbuild，正常 checkout 可直接 npm ci / npm test；补齐中英文说明与匿名演示截图。

## 安装

下载附件 dsh-branchman-0.3.1.tgz，按仓库 docs/INSTALL.md 在实际桌面 profile 安装并登记 bundle。已验证 @deepseek-ai/dsh-desktop@0.2.0-rc.2；其他宿主版本需重新核对合同。

升级会写入独立 tree-v2.json，并保留 v1 文件；未知历史基点保持恢复状态。

## 验证范围

112 项测试通过；实际桌面列表/图形、筛选、折叠、祖先搜索、相机保持与 pnpm install/prune 通过。1000 会话 / 100 根的合成纯布局 p95 为 11.21ms。

长期稳定性测试未执行；本机用户明确取消两小时门槛，该项未记为 pass。0.3.0 的 20 次冷启动及真实模型工具流是历史验证，本次没有重复声称运行。

## English

Separate main-tree cards and ancestry-aware layouts prevent unrelated branches from being interleaved. A collapsible outline, main-tree filters, ancestor-preserving search/pagination, readable initial zoom, focus control and optional details improve navigation. This release also includes the integrated v2 runtime, stable identities, verified Git/file carry and recoverable operation journals from 0.3.0.

Verified with @deepseek-ai/dsh-desktop@0.2.0-rc.2. 112 tests pass. The two-hour stability campaign was explicitly waived locally and is not reported as passed. v1 migration preserves the original file; missing historical bases remain recovery states. Demo screenshots contain synthetic data.
